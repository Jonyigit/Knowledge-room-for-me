# THE KNOWLEDGE ROOM

Shaxsiy bilim markazi — mavzular, iqtiboslar va bilimlar bazasi.

## Xususiyatlar

- 📚 **Mavzular** — o'rganmoqchi bo'lgan mavzularni kuzatish
- 📊 **Progress** — umumiy taraqqiyot ko'rsatkichi
- 💬 **Iqtiboslar** — eshitgan/o'qigan so'zlarni saqlash
- 🧠 **Bilimlar bazasi** — o'rgangan hamma narsa
- 🌙 **Dark / Light mode**
- 💾 **localStorage** — barcha ma'lumotlar brauzerda saqlanadi
- 📤 **JSON eksport**

## Texnologiyalar

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- Hech qanday framework, build tool yoki bog'liqlik yo'q
